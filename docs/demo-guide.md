# 5분 시연 가이드

## 1. 정상 개인화 · 약 1분

시나리오 스튜디오 → 급여 입금 → Agent 실행. 기본 고객 C0001의 기존 잔액에 입력한 급여를 더한 컨텍스트로 분석합니다. 고객 분석 → 기회 발견 → 콘텐츠 → 정책 → 여정을 확인합니다. 고객 선택에서 동의 체크 후 연결하면 Performance 단계가 집계됩니다.

## 2. 통제 사례 · 약 1분

- 수신 동의 없음(C0004): Compliance에서 차단, 발송 0건
- 발송 빈도 초과(C0005): 최근 7일 3회 제한으로 차단
- Do Nothing(C0006): 기회 없음으로 콘텐츠 생성 이전에 종료
- Agent 장애: Customer Insight가 실패하며 이전 단계 기록이 유지됩니다. 재시도하면 실패 단계부터 이어집니다.

같은 고객에게 3회 안내하면 이후 이벤트는 정책에 따라 차단됩니다. 반복 시연이 필요하면 다른 고객을 선택하거나 새 DB 경로로 별도 서버를 실행하세요. 기존 기록을 자동 삭제하지 않습니다.

## 3. 담당자 협업 · 약 1분

캠페인 Co-Pilot에 브리프를 입력합니다. ‘조건 자동 채우기’로 도메인/금액을 반영한 뒤 직접 확인합니다. 조건별 후보, 제외 사유, 최종 대상, 과거 발송과 중복을 확인하고 A/B 문구·예산을 검토합니다. 담당자 승인 후에만 시연 발송을 기록합니다. 예산을 0원으로 설정하고 푸시를 선택하면 초과를 차단하는 경우도 볼 수 있습니다.

## 4. 실시간 모니터링 · 약 1분

시나리오 스튜디오의 자동 트래픽을 켭니다. 대시보드에서 동시에 움직이는 실행 상태, 분포 차트, 라이브 이벤트를 확인합니다. 점이나 행을 선택해 단계별 입력·출력과 감사 이력을 확인합니다. 트래픽은 2분 후 자동 종료되며 중지 버튼으로 바로 멈출 수 있습니다.

‘화면 일시정지’는 조회 화면만 멈춥니다. 서버의 작업은 계속 진행합니다. 실제 데이터가 없는 시간 범위에서는 차트가 비어 있습니다. 조회 범위를 늘리거나 이벤트를 실행하세요. 최초 진입 시 최근 15분에 기록이 없으면 1시간/24시간으로 넓혀 보여줍니다.

## 5. 성과와 기록 · 약 1분

성과 리포트 → 최근 7일 → 리포트 생성. 발송·열람·클릭·서비스 연결 퍼널과 A/B 결과를 확인하고 CSV나 인쇄/PDF로 저장합니다. 생성 후 새 작업이 들어와도 저장된 리포트는 변경되지 않습니다. 감사 로그에서 승인, 고객 선택, 시연 발송, 정책 차단의 근거를 추적할 수 있습니다.

## 실제 연동 범위

API 키 없는 기본 모드는 규칙·템플릿 시연입니다. `.env` 설정으로 실제 LLM 문안 생성을 연결할 수 있지만, 외부 채널과 금융 서비스는 별도 어댑터를 구현해야 합니다. 사용자 인증과 운영 배포는 이 로컬 시연 버전에 포함되지 않습니다.
